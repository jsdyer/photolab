Sanitize the selected batch

Up to 20 files and 192 MiB combined. Whole images are re-encoded sequentially; editor adjustments are not applied to the batch.

Re-encoding strips metadata and Content Credentials. It can change compression and colour. Large images are fitted within 8,192 pixels per side and 24 megapixels. JPEG fills transparency with white. Animated PNG and unsupported files are skipped. Visible names, faces or addresses in pixels remain.

Privacy and export details

Photo Lab inspects supported metadata containers and decodes pixels locally. Every clean export is scanned again before download. The check requires a complete JPEG/PNG structure with no EXIF, XMP, IPTC, comments/text, C2PA or unknown metadata containers. Basic image structure and colour/rendering parameters remain. It does not inspect visible personal information or steganography. JPEG fills transparent regions in white. Export dimensions are capped at 8,192 pixels per side and 24 megapixels. A JSON report may include sensitive GPS coordinates present in the original. PNG specification · C2PA specification.
